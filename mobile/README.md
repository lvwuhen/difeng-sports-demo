## 覆盖的 C 端功能点（依据建设方案 3.6.12）

- 登录与授权：以微信授权后的会员身份进入，手机号脱敏展示。
- 场馆查询 / 场地查询：区域筛选、距离、营业时间、场地类型与状态。
- 场地预约：30 分钟起订、连续时段、跨时段计价、VIP 加价，锁定占用时段。
- 在线支付：微信支付（兴E付聚合收单）、储值余额、次卡抵扣；支付结果与订单状态联动。
- 订单管理：待支付、待使用、已完成、已取消、退款中；取消释放时段、退款原路退回。
- 电子核销：支付成功生成核销码与二维码，订单详情可刷新、可展示。
- 会员储值：电子会员卡、本金与赠送分账、充值档位赠送、积分展示、收支流水。
- 次卡：在线购买、剩余次数、有效期、使用记录，下单时按运动类型抵扣。
- 赛事活动：线上报名、组别与名额、报名表单、线上支付、报名电子凭证。
- 电子发票与消息通知：订单开票申请/查看、开票信息维护、站内消息中心。
- 优惠券 / 积分抵现：方案中本期仅保留配置能力，原型只保留入口与说明，不虚构活动规则。

## 交互与数据

- 数据为本地 Mock，统一存放在 `localStorage` 键 `df_mobile_v1`，刷新不丢失；外壳右上可重置。
- 主流程：首页 → 场馆 → 选场 → 选时段 → 确认订单 → 模拟支付 → 支付结果（核销码）→ 订单详情。
- 文件边界：全部新增文件位于 `mobile/`，未修改后台原型根目录文件与 `pages/` 后台页面。
